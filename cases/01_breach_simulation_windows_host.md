# 案例 01 · 入侵预演：一台 Windows 宿主机

> 小黑 · 攻击者视角入侵预演（防御性威胁建模）
> **本案例为教学样例**：所有 IP、用户名、路径、端口、进程均为占位演示，不含任何真实主机信息。

---

## 这是什么

用攻击者视角，对一台典型 Windows 开发宿主机做一次"如果我是黑客，我会怎么打进来"的推演。
目的不是真攻击，而是**照着黑客的路线检查自己有没有防住**。

- 手法来源：公开通识（MITRE ATT&CK 等）
- 可信度：`DEGRADED`（示例推演，非真实测绘、非一手情报）
- 红线：只做防御建模，不生成任何可运行攻击代码

---

```text
监听端口（对外/本地混合，示例值）：
  <面板端口>   0.0.0.0 / ::     <管理面板进程>       ← 对外管理面板
  135          0.0.0.0          svchost (RPC)        ← RPC/DCOM
  139/445      0.0.0.0          System (SMB)         ← 文件共享

防火墙：三档均启用；<面板端口> 有一条 Allow/Any 放行规则
RDP：关闭
默认共享：C$ / D$ / ADMIN$ / IPC$ 存在
管理员账户：内置管理员 + 当前用户 + 域/组（占位）
```

### 假想敌（示例）

组合：**机会型黑产勒索团伙 + 扫描型 APT**——典型路径是"扫管理端口 → 打弱口令 → 拿 shell → 横向/勒索"。均为公开通识画像，`DEGRADED`。

### 预计入侵链（经典红队 8 阶段）

| 阶段 | 攻击者会怎么做 | 本机对应（示例） |
|---|---|---|
| 1 侦查 | 全网扫管理端口 | `<面板端口>` 对外 + 放行 → 公网可见 |
| 2 初始访问 | 打管理面板弱口令/默认口令/CVE | 面板 = Web 登录入口，口令是唯一屏障 |
| 3 执行/持久化 | 面板内文件管理/计划任务落后门 | 面板自带文件与任务功能，拿到 ≈ 拿到 shell |
| 4 权限提升 | 面板多为高权限服务运行 | 拿到面板 ≈ 整机权限 |
| 5 防御绕过 | 合法工具滥用 | 防火墙开着，但面板端口明确放行 |
| 6 凭据访问 | 读配置/密钥文件 | 主机存有各类本地工具配置 |
| 7 横向移动 | 默认共享 C$/D$/ADMIN$/IPC$ | 四个默认共享存在（RDP 关闭是唯一好消息） |
| 8 数据外传 | 加密通道外带 | SMB 监听 + 多网段示例 |

### 三步法排序

1. **暴露面**：`<面板端口> 对外管理面板` ≫ `135 DCOM` > `139/445 SMB` > `127.0.0.1 本地服务（外部打不到）`
2. **最弱环节**：**管理面板口令**——单口令登录、无二次验证示例；命中后 3-8 步几乎自动完成
3. **最高价值目标**：**主机 shell ≈ 整机**（面板能执行文件/任务操作）> 凭据 > 代码

### 防御自查结论

- 🔴 高危：管理面板公网放行 + 单口令 = 最可能先倒下的一环。自查：口令强度、默认端口是否改、有无 IP 白名单、面板是否最新
- 🟡 中危：135 DCOM 放行；默认共享存在。非必要应关闭
- 🟢 守住：RDP 关闭；防火墙启用；核心服务只绑 127.0.0.1；SMB 入站规则多数禁用
- ⚪ 未验证：面板是否真能从公网连通（未做外部扫描，那属真实攻击）

**可信度：`DEGRADED`**——基于示例暴露面 + 公开通识推演，未实测可达性、未核实版本 CVE。
