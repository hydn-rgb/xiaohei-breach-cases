# 小黑 · 入侵预演案例库

> **一句话**：用黑客的眼光，把你的系统先"打"一遍，看看哪里会先倒下——只推演，不攻击。

`小黑` 是一个**防御性威胁建模**项目：站在攻击者视角，按经典红队手法推演"我会怎么打这台机器/这个方案"，然后反过来检查自己有没有防住。所有案例均为**脱敏教学样例**，不含真实主机、真实用户、真实漏洞信息。

## 它是什么 / 不是什么

- ✅ **是**：攻击者视角自查清单、入侵链推演、警示风格的预演报告
- ❌ **不是**：渗透工具、漏洞利用、勒索软件、任何可运行的攻击代码

## 方法论

- **分类体系（吞并 MITRE ATT&CK）**：小黑 8 阶段 = ATT&CK 战术的防御友好版前端（侦查/资源开发 → 初始访问 → 执行/持久化 → 提权 → 隐蔽/防护损害 → 凭据访问 → 横向移动/收集 → C2/外传/影响）。只吸收分类与自查视角，不吸收任何攻击执行能力；列数随 ATT&CK 版本扩展。
- **攻击者三步法**：暴露面 → 最弱环节 → 最高价值目标
- **可信度纪律**：公开通识推演一律标 `DEGRADED`，不伪装成已核实情报

## 假想敌

- 机会型黑产勒索团伙 / 扫描型 APT（公开通识画像）
- 国内安全厂商公开信源（火绒/360）/ 国际知名黑客（仅作手法画像，不点名指控）
- 社区同类工具参考（一手页面核实，非榜单）：[MITRE ATT&CK](https://attack.mitre.org)（手法字典）、[Atomic Red Team](https://github.com/redcanaryco/atomic-red-team)（检测测试库）、[Apache CALDERA](https://github.com/apache/caldera)（重型模拟平台，官方警告勿暴露公网）、[OWASP Threat Dragon](https://github.com/OWASP/threat-dragon)（威胁建模画图）。小黑只借用它们的手法分类做自查，不运行其攻击能力。

## 新项目默认安检

新项目/新方案立项时，**默认先过一遍小黑入侵预演**再开发：只读观察暴露面 → 按红队手法清单逐条自查 → 输出分级结论（🔴高危/🟡待加固/🟢已防/⚪未实测）→ 全标 `DEGRADED`。不执行真实攻击、不读密钥、不改配置。

## 边界

只做防御性威胁建模。所有输出是"用来照着检查自己"的推演，不是攻击工具。真实扫描、弱口令测试、外部可达性探测都不在本项目范围内——那些需要你本人在授权环境下做。
